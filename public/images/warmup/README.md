# Warm-up images

One image per move, named `<id>.webp` (ids are in `src/data/warmup.js`, `WARMUP_MOVES`).
Same style as the exercise images: the mustache character on a white background, square or 3:2 (shown whole, not cropped),
converted to WebP up to 600 px. Until an image exists, the move's emoji is shown.
