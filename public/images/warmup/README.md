# Warm-up images

One image per move, named `<id>.webp` (ids are in `src/data/warmup.js`, `WARMUP_MOVES`).
Same style as the exercise images: the mustache character on a white background, square (shown in a square frame, like other exercise pictures),
converted to WebP up to 600 px. Until an image exists, the move's emoji is shown.

Current moves: jumping_jacks, neck_tilts, shoulder_rolls, arm_circles, wrist_rolls, hip_circles, knee_circles,
ankle_rolls, arm_swings, torso_twists, side_bends, air_squats (bodyweight, no barbell), knee_hugs, leg_swings.
